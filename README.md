# Tubes-ALGORITMA-PEMOGRAMAN-2
# 📝Tugas Besar Alpro2 Kelompok 7, Topik: KursuIn
KursusIn adalah aplikasi untuk mengelola registrasi peserta pada berbagai program pelatihan
digital. Data utama yang digunakan adalah data peserta, data katalog kursus, dan data bidang
minat. Pengguna aplikasi adalah admin pendaftaran atau koordinator kursus.

## 🛠️SPESIFIKASI
1. Pengguna dapat menambahkan, mengubah, dan menghapus data peserta kursus.
2. Sistem dapat mencatat tanggal pendaftaran dan pilihan bidang minat yang diambil oleh setiap peserta.
3. Pengguna dapat mencari data peserta berdasarkan bidang minat atau nama lengkap menggunakan Sequential dan Binary Search.
4. Pengguna dapat mengurutkan data peserta berdasarkan ID pendaftaran atau nama secara alfabetis menggunakan Selection dan Insertion Sort.
5. Sistem dapat menampilkan statistik jumlah pendaftar untuk setiap bidang minat dan total peserta aktif.

<br><br>
## 🤔PENJELASAN MENU UTAMA 
1. Tambah Peserta: Menambahkan data peserta kursus baru ke dalam sistem (misalnya menginput Nama).
2.Tampilkan Data: Menampilkan daftar lengkap seluruh peserta kursus yang telah terdaftar ke layar terminal.
3. Ubah Peserta: Memperbarui informasi data peserta yang sudah ada di dalam sistem berdasarkan pencarian data tertentu.
4. Hapus Peserta: Menghapus data peserta dari daftar kursus di dalam sistem.
5. Sequential Search Nama: Mencari data spesifik berdasarkan Nama peserta dengan mengeceknya satu per satu dari awal hingga akhir data (pencarian linear).
6. Sequential Search Bidang: Mencari dan menampilkan daftar peserta berdasarkan kategori Bidang kursus tertentu secara berurutan.
7. Selection Sort ID: Mengurutkan daftar peserta berdasarkan nomor ID dari yang terkecil ke terbesar (ascending) menggunakan metode Selection Sort.
8. Insertion Sort Nama: Mengurutkan daftar peserta berdasarkan abjad Nama (A-Z) menggunakan metode Insertion Sort.
9. Binary Search Nama: Pencarian data super cepat berdasarkan Nama peserta (dengan syarat data nama harus sudah diurutkan sesuai abjad terlebih dahulu oleh program).
10. Statistik: Menampilkan laporan ringkas, misalnya berupa total keseluruhan peserta atau jumlah peserta pada masing-masing bidang kursus.
11. Keluar: Menutup aplikasi dan menghentikan program dengan aman.
