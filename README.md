# 📝Tugas Besar Alpro2 Kelompok 7, Topik: KursuIN
KursusIn adalah aplikasi untuk mengelola registrasi peserta pada berbagai program pelatihan
digital. Data utama yang digunakan adalah data peserta, data katalog kursus, dan data bidang
minat. Pengguna aplikasi adalah admin pendaftaran atau koordinator kursus.
